Comment fonctionne mon collecteur de flux RSS ?

Qu'est-ce qu'un flux RSS ?

Un flux RSS (Really Simple Syndication) est un fichier XML mis à jour automatiquement par un site web. Il contient les derniers articles publiés avec leur titre, date, description et lien. C'est un standard utilisé par la plupart des sites d'actualités.

Le problème : les restrictions CORS

Les navigateurs web bloquent les requêtes vers d'autres domaines pour des raisons de sécurité (politique CORS - Cross-Origin Resource Sharing). On ne peut donc pas directement récupérer un flux RSS depuis JavaScript dans un navigateur.

La solution : l'API rss2json.com

J'utilise l'API gratuite rss2json.com comme intermédiaire. Cette API récupère le flux RSS côté serveur, le convertit en format JSON (lisible par JavaScript), puis me renvoie les données. Cela contourne les restrictions CORS.

Affichage dynamique

Les articles sont ensuite triés par date (les plus récents en premier), formatés et affichés dynamiquement dans l'interface. Un système de données de secours garantit l'affichage même si l'API est indisponible.
